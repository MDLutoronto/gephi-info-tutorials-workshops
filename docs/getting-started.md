Getting started
---------------

* You can [download the installation files for Gephi](https://gephi.org/desktop/) for Windows, Mac OS, and Linux
* There are a few short installation instructions found at the top of the [Quickstart page](https://gephi.org/quickstart/)
* Alternatively, Gephi has also just launched a new web browser version, called [Gephi Lite](https://gephi.org/lite/), if you want a quick look at the tool before installing it
